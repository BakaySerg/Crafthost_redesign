Data Processing Agreement (DPA).

Data Processing Agreement Roles & Responsibilities Categories of Data Processed Subprocessing International Data Transfers Confidentiality Security Measures Customer Instructions Data Subject Rights Assistance Breach Notification Data Retention & Deletion Audits & Compliance Documentation Liability Duration & Termination Contact Information

Last Updated: 2025

This Data Processing Agreement (“DPA”) forms part of the Service Agreement (“Agreement”) between Crafthost SRL (“Processor”) and the customer receiving Crafthost services (“Controller”).

It governs the processing of personal data carried out by Crafthost on behalf of the Controller in connection with Managed Hosting and Managed Infrastructure-as-a-Service (IaaS) solutions.

This DPA applies to all Crafthost services where personal data is processed, including cloud hosting, dedicated servers, private cloud environments, database hosting, migration services, security solutions, and managed operations.

Governing law reference : Italy.

1. Purpose & Scope.

  1. This DPA defines how Crafthost processes personal data exclusively on documented instructions from the Controller.
  2. The provisions apply to all environments including production systems, backups, DR sites, monitoring systems, and support interactions.
  3. Crafthost does not determine the purpose or means of processing; the Controller retains full responsibility for configuration, content, and classification of the stored data.

2. Roles & Responsibilities.

Controller

  • Determines categories of data and legal basis
  • Manages end-customer rights
  • Ensures data uploaded to Crafthost is lawful

Processor (Crafthost)

  • Processes data only under instructions
  • Implements security, monitoring, encryption, and restricted access
  • Provides infrastructure supporting compliance with GDPR and other regulations

3. Categories of Data Processed.

Depending on the Controller’s use of Crafthost services, the data may include:

  • Account data
  • Contact data
  • Billing information
  • Server-level data stored or transmitted by the Controller
  • Logs, metadata, metrics, and service analytics
  • Configuration and system information
  • Authentication and access data for management operations
  • Support communications and troubleshooting content

Crafthost does not require access to the Controller’s customer content unless explicitly requested during support or management tasks.

4. Subprocessing.

  1. Crafthost uses carefully selected subprocessors to operate infrastructure components such as datacenters, CDN nodes, network carriers, support tools, and backup storage.\
  2. The complete Subprocessors List is published at: /subprocessors-list/
  3. Before adding a new subprocessor, Crafthost performs due-diligence covering:
    • Data access scope
    • Security controls
    • Geographic location
    • Compliance certifications
    • Contractual protections
  4. Controller will be notified of material changes to the list.

5. International Data Transfers.

  1. Data may be processed in Crafthost’s global datacenter regions selected by the Controller.
  2. If data is transferred outside the European Economic Area (EEA), such transfer will rely on:
    • Standard Contractual Clauses (SCCs)
    • Adequacy decisions
    • Additional encryption and security safeguards
  3. Crafthost ensures no transfer contradicts applicable data protection laws.

6. Confidentiality.

  1. Crafthost employees and contractors are bound by strict confidentiality obligations.
  2. Access to data is restricted using:
    • Role-based access control
    • Privileged access management
    • Multi-factor authentication
    • Session logging and reviews
  3. Personnel are trained on privacy and cybersecurity requirements.

7. Security Measures.

Crafthost maintains enterprise-grade security aligned with ISO 27001, SOC 2, and modern cloud security frameworks.
Core controls include:

Infrastructure Security

  • Segmented networks
  • DDoS protection
  • Firewalls and WAF
  • Redundant power and connectivity
  • Physical datacenter security (biometrics, surveillance, man-traps)

Data Security

  • Encryption in transit (TLS 1.3)
  • Encryption at rest (AES-256)
  • Key management and rotation
  • Secure storage of backups

Operational Security

  • 24/7 monitoring
  • Security incident detection
  • Patch management and vulnerability scanning
  • Logging and audit trails

Application & Access Security

  • MFA for all management systems
  • Zero-trust authentication principles
  • IP-restricted dashboard access (optional)

8. Customer Instructions.

  1. Crafthost processes personal data only in accordance with documented instructions received through:
    • Service configuration
    • Tickets
    • Contracts
    • Written agreements
  2. Crafthost will notify the Controller if an instruction is found to be unlawful.

9. Data Subject Rights Assistance.

Crafthost assists the Controller in fulfilling requests regarding:

  • Access
  • Restriction
  • Rectification
  • Portability
  • Erasure
  • Objection

Assistance covers technical measures such as retrieving logs, removing snapshots, or exporting data.

10. Breach Notification.

  1. In the event of a data breach affecting personal data, Crafthost will notify the Controller without undue delay.
  2. The notification will include:
    • Nature and scope of the breach
    • Categories of affected data
    • Mitigation measures applied
    • Actions taken to prevent recurrence
  3. Crafthost will provide ongoing updates throughout the investigation.

11. Data Retention & Deletion.

  1. At contract termination, the Controller may request:
    • Secure deletion
    • Data export
    • Transfer to another processor
  2. Backups, logs, and caches follow the retention periods defined in the Data Retention Policy.
  3. Upon confirmation, deletion is performed using secure wiping protocols.

12. Audits & Compliance Documentation.

  1. Crafthost provides compliance documentation including:
    • ISO certifications
    • SOC 2 reports (where applicable)
    • Security summaries
    • Infrastructure descriptions
    • Penetration test summaries
  2. Where legally required, reasonable audits may be performed under confidentiality and mutually agreed conditions.

13. Liability.

Liability is governed by the main Service Agreement. This DPA does not expand Crafthost’s liability beyond what is agreed in the primary contract.

14. Duration & Termination.

  1. This DPA remains in force for as long as Crafthost processes data on behalf of the Controller.
  2. Termination follows the procedures of the main Service Agreement.
